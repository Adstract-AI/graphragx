# Answer and Explanation Output

Return the final answer generated by the LLM, along with an optional explanation based on the retrieved subgraph.

---

## Objective

Provide a clear answer to the user and, if needed, include supporting reasoning derived from the graph context.

---

## Input

- `answer`: output from the LLM  
- `context`: textualized subgraph (optional for explanation)  

---

## Output

- `answer`: final response  
- `explanation` (optional): supporting statements derived from the context  

---

## Notes

- The explanation can reuse relevant parts of the textualized subgraph.
- Including explanations improves transparency and interpretability.
- This step does not modify the answer, only formats and presents it.
---
